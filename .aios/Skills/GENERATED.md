# Generated — do not hand-edit

`aios-notes/` and `aios-notes.plugin` in this folder are **build output** of the upstream
`aios-notes` skill pack (its `plugin/` folder).

To change anything here: edit the skill pack, bump its version, rebuild, and sync the output into
this folder. Never edit these copies by hand.

Hand-editing a copy is how drift happens: two copies with no common ancestor end up files apart,
and a build from the stale one ships a silent regression.
