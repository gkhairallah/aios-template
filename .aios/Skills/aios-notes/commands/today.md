Use the **vault-ops** skill (Daily log operations). Input: $ARGUMENTS

Open or create today's daily note.

- **Starting the day** — help set the 🎯 Top 3 from the operator's own items only (no `owner::`),
  then list open **👀 Watching** items separately, grouped by owner, with escalations flagged. A
  watch item is never offered as a Top 3 pick — see Conventions § 👀 Mine vs Watching.
- **Wrapping up** (`wrap`, "fill in what I missed", "what did I not log") — load
  `references/day-wrap.md` and follow it: sweep the day's reachable sources, diff against what's
  already in the log, and present the missing rows, Worked On links and 🌙 Evening Review as a
  draft to correct, approve or reject.
- **Reviewing** — run the 🌙 Evening Review (Wins / Blockers / Extract / Energy) on its own.

Show changes; write on approval. Unattended runs never write into the log tables — see the
day-wrap reference.
