# Gather external context

Use this wrapper when the user asks to check a connected document store, email, calendar,
chat platform, or record system (tickets, issues, CRM); find company context; or enrich a
note with connected-source information.

The authoritative workflow is `.aios/Skills/aios-notes/skills/gather/SKILL.md`. Read and
follow it; resolve sources capability-first using the tools actually available in this
session — including any gateway it exposes — retain its targeted-search and approval
requirements, and do not reproduce or bypass its rules.

This route is read-only with respect to the connected source. Anything that creates,
updates, sends, or deletes hands off to `.codex/workflows/act.md`.
